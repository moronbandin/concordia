# Concordia

Modelo visual e manipulable da flexión latina e grega, preparado como sitio estático para GitHub Pages.

## Estrutura

- `index.html`: estrutura e navegación.
- `styles.css`: sistema visual compartido e modo aula.
- `app.js`: interaccións e renderizado común.
- `latin-data.js`: paradigmas e exemplos latinos.
- `greek-data.js`: paradigmas e exemplos gregos.

Non require compilación nin dependencias. Para engadir unha lingua ou ampliar unha existente, os paradigmas deben vivir no seu ficheiro de datos e a presentación reutilizar os compoñentes de `app.js`.
